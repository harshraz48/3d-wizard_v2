# 3D Wizard

Portable React + TypeScript + Tailwind CSS website, built with Vite. Includes all pages, reusable components, and 35 assets. No ChatGPT hosting dependency, API keys, or environment variables.

## Run locally

Use Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

Production output: `dist/`. Commit the package-lock.json generated by npm install to lock subsequent dependency installs.

## Repository and deployment

Extract this ZIP and put the contents of `3d-wizard/` in your repository root, including `.gitignore`. Do not commit node_modules or dist.

Import your repository into Vercel or Netlify. Select Vite if prompted:

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: 22.13 or newer

The included vercel.json and netlify.toml configure fallback routing for direct links and refreshes. For other static hosts, serve existing assets normally and rewrite remaining requests to index.html with status 200. This project expects a domain-root deployment; subdirectory hosting requires asset and routing adjustments.

## Where to edit

- src/Wizard.tsx: pages and reusable Navbar, Footer, Freebie, Newsletter, Project Card, forms, accordion and help widget.
- src/main.tsx: entry point and pathname routing.
- src/index.css: Tailwind import, responsive styles and theme.
- public/assets/: all supplied images plus illustrative SVGs.
- index.html: title, description and favicon.
- vite.config.ts, postcss.config.js, tsconfig.json: build settings.

## Pages

Home, Services, Technologies, 3D Scanning, Vacuum Casting, Colours & Finishes, About, Contact, Freebie, FAQ, Projects and sample project details, Start Print, Resources, Legal.

## Before taking real enquiries or orders

Forms currently validate and confirm locally only. They do not send email, persist data, accept payments, or create shipments. Files remain in the browser. Connect your backend before taking customer orders.

Replace marked contact details, social links, equipment specifications, project examples, and draft policies. Confirm commercial claims and freebie terms with the business. The help widget is a help menu, not live chat.

This standalone export does not change the original deployed site.
